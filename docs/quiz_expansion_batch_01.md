본 문서는 ‘한알국쉬 2.0’의 시범판(고전 10문항, 독서 9문항) 확정에 이어, 현재 활성 DB(`js/data.js`)에서 새롭게 선정한 **20개 어휘의 1차 확대 검토용 문항 문서**입니다.

새로 보완된 **‘문항 제작 기준’(`docs/quiz_authoring_guidelines.md`)**을 엄격히 준수하여:
1. **“어휘 자체의 어려움에 문장과 배경지식의 어려움까지 더하지 않는다”**는 대원칙 아래 평이하고 명료한 문장으로 서술하였습니다.
2. **뜻 확인형(10개)을 대략 절반의 기본 바탕**으로 두고, 나머지 절반(10개)은 어휘 성격에 맞춰 **문맥 속 뜻 고르기(6개)·상황에 맞는 용어 고르기(3개)·빈칸형(1개)**으로 안배하였습니다.
3. 고전·문학(10개)과 독서·비문학(10개) 영역을 균형 있게 구성하였습니다.
4. 검토 시 정답 편중을 방지하기 위해 **정답 위치를 ①~④번에 고르게 분산**(①번 6개, ②번 5개, ③번 5개, ④번 4개)하였습니다.
5. **본 20문항은 검토 전용 문서로 작성되었으며, 서비스 코드나 로컬 웹 실행 데이터에는 탑재하지 않습니다.**

  - **최종 판단**: 평가하려는 학술적 의미의 사전 직접 열람 근거 미확보에 따라 **검토 보류** 처리.
- **제시문 출처 유형**: 학습용 창작 예문 (제시문 끝의 정답 정의 반복 구문 “~태도를 환원이라고 한다”를 전면 제거하고 연구자의 자연스러운 행동 서술로 수정)
- **남은 검토 사항**: 평가 대상 학술 의미의 공인 사전 표제어/URL/식별자 추가 확보 필요.

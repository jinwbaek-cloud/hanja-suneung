## 1. 사전 자료 공개 서비스 재이용 조건 및 검토 원칙

국립국어원 표준국어대사전 공식 누리집의 **저작권 정책**(`/join/copyrightPolicy.do`)을 직접 열람하여 확인한 법적·제도적 기준과 본 검토의 세부 원칙은 다음과 같습니다.

1. **기본 공공누리 / CC 라이선스**:
   - 표준국어대사전에서 별도로 출처가 명시되지 않은 일반 텍스트 자료는 **‘크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국 라이선스(CC BY-SA 2.0 KR)’**에 따라 배포됩니다.
   - 상업적 이용을 포함하여 자유롭게 이용할 수 있으나, **저작자 표시** 및 **동일조건변경허락** 의무를 준수해야 합니다.
2. **별도 출처가 있는 예문(용례)의 취급 안내**:
   - **공식 규정 원문**: *"텍스트 자료 중 출전이 있는 용례는 원저작자가 저작권을 소유하고 있으므로 원저작권자에게 문의하셔서 이용 허락을 받아야 합니다."*
   - 표준국어대사전 예문 중 현대 소설(이문열, 최명희, 이청준, 현기영, 김원일 등)에서 인용한 문장은 국립국어원의 자유이용 라이선스 범위에 포함되지 않으며 원저작자에게 저작권이 유보되어 있습니다. 따라서 실제 퀴즈 문제로 탑재할 경우 원저작자의 이용 허락을 받거나 독립적인 학습용 창작 예문으로 대체해야 합니다.
3. **‘출처 미표기’ 예문에 대한 엄정 취급 원칙**:
   - 사전 내에 서명이나 작가명이 별도로 적혀 있지 않다고 해서 **국립국어원이 직접 창작·작성한 예문이라고 단정하지 않습니다.**
   - 편찬 당시 민간 용례를 채록했거나 관용 표현을 수록했을 가능성이 있으므로, 본 보고서에서는 이를 **‘출처 미표기 (원저작자/작성처 미확인)’**으로 명시하며, 법적 이용 조건(CC BY-SA 적용 범위)과 예문 작성 주체의 확인 여부를 엄격히 분리하여 기록합니다.

## 2. 검증 영역의 5단계 구분 기준

각 어휘의 데이터 상태를 명확히 파악하기 위해 다음 5개 영역을 상호 독립적으로 구분하여 기록합니다.

| 검증 영역 | 평가 기준 및 내용 |
| :--- | :--- |
| **① 사전 등재 여부** | 국립국어원 표준국어대사전에 독립 표제어로 수록되어 있는지 여부 (등재 확인 vs 미등재/확인 보류) |
| **② 사전 예문 출처 확인** | 사전 내 예문의 출처 표기 유무 (출처 미표기 vs 문헌·작가명 표기 vs 사전 예문 없음) |
| **③ 이용 조건 확인** | CC BY-SA 2.0 KR 적용 가능 여부, 원저작자 저작권 유보에 따른 이용 허락 필요 여부 |
| **④ 출제 적합성** | 빈칸 치환 시 주변 문맥의 대조·인과 등 의미 추론 단서의 충분성, 지엽적 고난도 어휘 포함 여부 |
| **⑤ 기출 원문 대조** | 한국교육과정평가원 수능 및 모의평가 시험지 PDF 원문과의 1:1 대조 완료 여부 (미대조 시 문맥 해석 미검증 명시) |

## 4. 유형별 분류 요약 및 정합성 검토

본 집계는 위의 3절 개별 대조표와 완벽히 1:1로 일치합니다 (합계: 7 + 8 + 5 = 20개).

1. **문맥 적용형 후보 (7개)**:
   - `박장대소`, `임천`, `홍진`, `야인`, `수중고혼`, `가인`, `소일`
   - **판단 이유**: 문장 내에 빈칸 어휘를 지칭하는 대조(노파 ↔ 가인, 평정할 큰 재주 ↔ 임천), 인과(거센 물살 ↔ 수중고혼, 재치 있는 말 ↔ 박장대소, 무료함 달래기 ↔ 소일)의 확실한 의미적 단서가 존재함.
   - **주의점**: 이 중 `임천`, `홍진(김원일)`, `수중고혼`, `가인`, `소일(최명희)`은 현대 소설 인용문으로 원저작자 저작권이 유보되어 있어, 상용 서비스 반영 시 원저작자 이용 허락을 얻거나 독립적인 학습용 창작 예문으로 구성해야 함.

2. **뜻 확인형 우선 (8개)**:
   - `치군택민`, `전려`, `강호`, `진세`, `흠향`, `주달`, `발복`, `현알`
   - **판단 이유**:
     - 표준국어대사전에 예문이 아예 없거나(`치군택민`, `전려`, `흠향`, `주달`, `현알`), 짧은 구 형태만 있어 단서가 부족함(`강호`).
     - `진세`는 예문의 종교적·추상적 색채로 인해 타 유사어와의 구별 단서가 부족함.
     - **`발복`**: 사전 예문 2건 모두 현대소설 저작권 유보 출전이며, 문맥 속 사건 묘사만으로는 '운이 트여 복이 닥침'이라는 사전 정의를 객관적으로 유추할 단서가 부족함. 2025 6모 기출('당대발복')의 맥락도 조상 묘소 풍수지리적 개념어이므로, 어휘 뜻 자체의 개념적 이해를 묻는 뜻 확인형이 교육적으로 가장 타당함. (개별 표와 일치)

3. **추가 검토 필요 (5개)**:
   - `적강선녀`, `백년기약`, `군자호구`, `공후배필`, `전별`
   - **판단 이유**:
     - 표준국어대사전에 독립 표제어로 등재되지 않은 고전 합성어·고사성어(`적강선녀`, `백년기약`, `군자호구`, `공후배필`)로, 구성 단어 분해 및 기출 작품과의 맥락 연계 검토가 선행되어야 함.
     - **`전별`**: 수집된 두 사전 예문이 모두 현대소설 저작권 유보 출전이며, 예문 ②의 '상목', '역로' 등 지엽 어휘 난도가 높고 단순 배웅보다 노자 지급 정황이 두드러져 4지선다 출제 시 맥락 정립에 추가 검토가 필요함. (개별 표와 일치)

# 연구 통계 및 기술 지표 교정 감사 기록부 (Correction Log)

## 1. 개요

본 문서는 **Phase 6B 연구 통계 교정 감사(Research Metrics Correction Audit)**에 따라, Phase 6에서 산출된 연구 통계, 수치, 용어, 인과 서술을 Git 실제 커밋 객체, 커밋별 `js/data.js`, 보존된 `research/evidence/` 매니페스트 원자료에 재대조하여 정밀 교정한 내역을 기록한 공식 감사 일지이다.

모든 항목은 다음 5가지 상태(STATUS)로 분류하여 판정하였다.
- **`CORRECTED`**: 기존 주장에 수치적 또는 개념적 오류가 확인되어 정확한 사실로 수정한 항목.
- **`DOWNGRADED`**: 근거 범위를 초과하여 과장되었거나 단정적인 표현을 실제 검증 수준에 맞추어 완화한 항목.
- **`CONFIRMED`**: 원자료 및 Git 객체 대조 결과 사실과 완벽히 부합함을 재확인한 항목.
- **`REMOVED`**: 사실적 근거가 결여되었거나 다중 지표의 단순 합산으로 밝혀져 삭제한 항목.
- **`ESTIMATED`**: 확정된 단일 참값이 아니라 방법론적 가정에 기반한 추정치임을 명시한 항목.

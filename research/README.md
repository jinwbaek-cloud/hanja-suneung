# 한알국쉬 수능 연구 기록 및 감사 보고서 (Research & Audit Records)

## 1. 개요 및 목적

본 `research/` 디렉터리는 **한알국쉬 수능([suneung.easyhanja.org](https://suneung.easyhanja.org/))**의 코퍼스 구축, 단계별 편찬 검증, AI 생성 오류 색출 및 교정 과정에 관한 모든 연구 통계와 작업시간 감사 기록을 보존하기 위해 생성되었습니다.

- **기준 최종 배포 HEAD**: `a18f436`
- **최종 코퍼스 규모**: 701 표제어 / 879 기출 문맥 / 17개 평가원 기출 전수
- **학술적 목적**: LLM 기반 코퍼스 편찬 시 발생하는 실제 오류(환각, 다의어 오염, 스키마 잔재, 출전 왜곡 등)의 실증적 분류 체계를 수립하고, AI 보조 연구의 투입 시간 및 공수를 객관적으로 측정·보고할 수 있는 근거를 제공함.

## 2. 디렉터리 구성 및 파일 설명

```text
research/
├── README.md                      # 본 연구 기록 안내 문서
├── project_metrics.json           # 기계 판독 가능한 최종 종합 연구 메트릭
├── git_timeline.csv               # 최초 배포부터 HEAD a18f436까지의 Git 커밋 전수 타임라인 (42개 커밋)
├── worktime_audit.json            # AntiGravity 세션 로그 기반 작업시간 감사 상세 기록
├── ai_error_cases.md              # 실증 오류 20선 및 9대 AI 오류 분류 체계(Taxonomy) 분석표
├── presentation_statistics.md     # 학술 발표 및 대외 보고용 핵심 인용문, 표준 통계 및 시간 표현
└── evidence/                      # 검증에 사용된 13개 핵심 JSON 매니페스트 원본 보존
```

### 각 파일 상세 설명

1. **`project_metrics.json`**:
   - 최종 데이터베이스 통계(표제어, 문맥, 출전, 갈래, 카테고리, 난이도, 사전 출처 분포), 체크포인트 이력, Git 통계, 작업시간 요약, 검증/정비 성과 지표를 일원화한 JSON 문서입니다.
2. **`git_timeline.csv`**:
   - Git 저장소의 전체 커밋 이력을 시간순으로 추출하여 커밋 해시, 작성 일시, 커밋 일시, 메시지, 변경 파일 수, 추가/삭제 라인 수를 기록한 CSV 파일입니다.
3. **`worktime_audit.json`**:
   - AntiGravity IDE 세션 트랜스크립트 로그를 바탕으로 산출한 경과시간(Wall-clock span)과 10분 임계치 기준 추정 순 작업시간(Active Working Time), 16개 작업 세션 분할 내역, 15개 세부 Phase별 소요 시간 분석을 담고 있습니다.
4. **`ai_error_cases.md`**:
   - 수능 코퍼스 편찬 중 실제로 발생하여 색출·교정된 20개 대표 오류 사례를 5개 열(오류 유형, 실제 오류, 발견 단계, 교정 방식, 연구적 의미)로 정리한 실증 분석 보고서입니다.
5. **`presentation_statistics.md`**:
   - 학술 발표나 논문에서 즉시 인용할 수 있는 4대 핵심 연구 명제, 작업시간 표현 표준 문장 3종, 10대 핵심 통계 지표, 대표 오류 5선을 선별한 문서입니다.
6. **`evidence/`**:
   - Phase 2부터 Phase 5까지의 단계별 검증 매니페스트 및 전수 감사 JSON 파일 13건을 원형 그대로 보존한 디렉터리입니다. 각 파일의 SHA256 해시값과 바이트 크기는 `project_metrics.json`에 영구 기록되어 무결성을 증명합니다.

## 3. 작업시간 산출 방법론 및 주의사항

### A. 총 경과시간(Wall-Clock Span) vs 추정 순 작업시간(Active Working Time)
- **총 경과시간(Wall-Clock Span)**: 최초 작업 로그의 타임스탬프부터 최종 작업 로그 타임스탬프까지의 단순 달력상 경과 시간입니다. 여기에는 연구자의 수면, 식사, 휴식, 기타 학술 업무 시간이 모두 포함되어 있습니다.
- **추정 순 작업시간(Active Working Time)**: AntiGravity 세션 트랜스크립트의 연속된 이벤트 간격($\Delta t$)에 대해 $\min(\Delta t, \text{threshold})$를 누적 합산하여 산출하였습니다.
  - **기본 대표값**: **10분 임계치** (10분 이상 활동이 없으면 해당 공백 전체를 비작업 구간으로 처리)
  - **민감도 분석**: 5분 임계치 및 15분 임계치 결과를 병기하여 추정의 신뢰도를 점검함.

- **FINAL EDITORIAL / VALIDATION RANGE (`7204b1d` ~ `a18f436`)**: **`ESTIMATED`**

> [!IMPORTANT]
> 본 작업시간 통계는 AntiGravity IDE 로그 기반의 활동 시간만을 측정한 것입니다. 수능 기출 문제지 실물 PDF 대조 및 국어사전 수동 교차 검토 등 IDE 외부에서 이루어진 순수 오프라인 인지 작업 시간은 포함되지 않았으므로, 실제 연구 투입 시간의 하한선(lower-bound)으로 해석해야 합니다.

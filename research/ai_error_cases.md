# AI 기반 어휘 코퍼스 편찬 과정의 오류 유형 및 실증 사례 분석 (AI Error Cases & Taxonomy)

## 1. 개요 및 연구적 배경

본 문서는 **한알국쉬 수능(suneung.easyhanja.org)** 구축 및 편찬 과정에서 발생한 LLM(인공지능)의 실제 데이터 오류, 환각(Hallucination), 스키마 오염, 그리고 후속 재오염(Downstream Recontamination) 현상을 실증적으로 분류하고 정리한 연구 기록이다.

본 분석에 포함된 모든 사례는 프로젝트의 `편찬일지.md`, Git commit 이력(`7204b1d` ~ `a18f436`), 그리고 검증용 매니페스트(`research/evidence/` 보존 문서)에 명시적으로 기록된 **실제 발생 오류(Actual Errors)**만을 대상으로 채택하였으며, 추정이나 가상의 위험은 별도 절로 명확히 분리하여 기술하였다.

## 2. AI 오류 분류 체계 (Evidence-Based Error Taxonomy)

실증 사례 분석을 바탕으로 확립된 9개 오류 분류 체계는 다음과 같다.

1. **Hanja Transcription Error (한자 전자/자형 오기 오류)**: 표제어의 한자 표기를 유사 자형, 약자, 또는 전혀 다른 한자로 잘못 입력하는 오류.
2. **Source/Provenance Fabrication or Mismatch (출전·작품명 오귀속 오류)**: 지문의 실제 출전, 작품명, 수록 단원, 시행 연월을 잘못 연결하거나 왜곡하는 오류.
3. **Corpus Boundary Error (코퍼스 범위 일탈 오류)**: 합의된 평가원 수능/모의평가 출제 범위 밖의 과거 레거시 데이터나 임의 예문이 코퍼스에 잔류·침투하는 오류.
4. **Context Fabrication/Misattribution (기출 문맥 조작 및 허위 생성)**: 실제 시험지 원문에 없는 문장을 마치 기출 지문인 것처럼 그럴듯하게 조작·요약하여 생성하는 오류.
5. **Dictionary-Source Mismatch (사전 표제어/출처 불일치)**: 표준국어대사전 또는 우리말샘에 실제로 등재되지 않은 단어이거나 지문 표기와 사전 표제어가 다른데도 공인 사전 출처로 기재하는 오류.
6. **Sense Contamination (동음이의어/다른 한자 의미 오염)**: 표제어의 한글 독음이 동일하다는 이유로, 기출 지문의 실제 한자 속뜻이 아닌 다른 동음이의어의 의미가 해설이나 분류 사유에 침투하는 오류.
7. **Legacy Metadata Contamination (레거시 스키마 잔재 오염)**: 초기 개발 단계의 더미 데이터, 비표준 빈 배열(`mock feed`), 또는 이미 무의미해진 레거시 필드가 DB에 잔존하는 오류.
8. **Downstream Recontamination (후속 파이프라인 재오염)**: 선행 단계에서 한자와 뜻풀이를 정밀 교정했음에도, 후속 분류(난이도·카테고리 판정) 단계에서 AI 프롬프트가 다시 잘못된 동음이의어 정보를 참조하여 오염을 재발시키는 현상.
9. **Automated Validation False Confidence (자동화 검증 과신 오류)**: 스키마 키의 존재 여부나 정규식 통과 등 기계적 구문 검증 통과를 코퍼스 사실성(Factuality) 통과로 착각하는 오류.

## 4. 잠재적 위험(Potential Risks)과 실제 오류(Actual Errors)의 구분

연구의 엄밀성을 위하여 본 프로젝트에서는 다음 두 범주를 엄격히 분리하여 관리하였다.

1. **실제 발생 오류 (Actual Errors - 검증 및 교정 완료)**:
   - 위 표에 제시된 20개 사례와 같이, Git commit diff 또는 manifest 파일 상에서 잘못된 값이 실제로 존재하다가 정밀 감사에 의해 색출·교정된 항목.
   - 예: `도외시(圖外視)`의 한자 오기, `사가(社歌)` 사유에 침투한 `私家` 해설, 25건의 기출 불일치 허위 문맥, 4건의 zero-context 고립 표제어 등.

2. **잠재적 위험 (Potential Risks - 구조적 방어 장치로 원천 차단)**:
   - **Open Graph / Twitter Card 가짜 이미지 위험**: 웹 배포 시 대표 이미지가 없을 때 존재하지 않는 임의 이미지 URL을 생성하여 OG 태그에 넣는 흔한 웹 개발 실수. 본 프로젝트는 Phase 5에서 가짜 이미지 생성을 원천 금지함으로써 사전에 차단함.
   - **Netlify 와일드카드 리다이렉트 무한 루프 위험**: canonical 설정 시 도메인 구분 없는 `/*` 301 리다이렉트를 임의 추가할 경우 발생할 수 있는 서비스 장애 위험. Phase 5에서 기존 설정 파일 부재를 확인하고 인위적 리다이렉트 룰 생성을 금지하여 원천 차단함.
   - **SEO Keyword Stuffing 위험**: 메타 태그 및 제목에 무분별한 키워드 나열이나 "점수 보장", "합격" 등 과장 광고 문구를 삽입하는 위험. 편찬 원칙을 통해 단정한 학술적·교육적 문구만 채택하여 차단함.
